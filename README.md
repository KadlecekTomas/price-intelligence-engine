# Price Intelligence Engine

Lokální price-intelligence platforma pro české e-shopy.

První adapter: **ABOUT YOU CZ / pánský katalog**. Architektura je od začátku připravená pro další e-shopy bez vazby core enginu na konkrétní storefront.

## Cíl

- sbírat aktuální ceny, původní ceny, 30denní minima a dostupnost variant,
- budovat vlastní cenovou historii,
- porovnávat skutečnou výhodnost nabídek místo marketingového procenta slevy,
- později párovat stejný produkt napříč českými e-shopy,
- běžet lokálně a následně umožnit přechod na PostgreSQL / serverové workery.

> Stav: bootstrap repository. Implementace lokální MVP probíhá na feature branchi.
